架构

七层架构，壳脑分离

渠道层与能力层彻底解耦——这是「外接」成立的根基。

渠道层挂件 / Email / TG / 外接
→
编排层状态机 / 归一 / 审计
→
大脑层extractive / pasm_cs
→
资产层客户 / 标签 / 轨迹
→
治理层RBAC / hash 链 / 频控

大脑是唯一可插拔层：默认抽取式（零依赖、不可能幻觉）；企业版可选 PASM 认知引擎（授权）。两种交付共用同一套壳。
