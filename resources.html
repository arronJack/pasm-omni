安全与合规

数据在你手里，动作可追溯

🔗

审计 hash 链

所有操作追加写入并链式 hash。篡改或删除任意一条，全链校验即时失败并定位断点—— 测试里实测可检出。

🚪

权限默认拒绝

工具级 RBAC：高危动作未显式授权即拒。没有「默认开放」这回事，拒绝也留痕。

🔒

越权防护（读写分离）

读接口与写接口同样要求身份：客户名单、访客轨迹、经营报表、会话列表、 知识库、审计日志、SSE 实时事件在开启账号体系后无 token 一律 401。 角色分 viewer / agent / admin 三级，审核权与提交权分离（agent 不能审自己的模板）。

📵

群发合规硬约束

群发总开关默认关闭；必须显式确认收件人已同意（opt-in）；频控 + 退订名单双重兜底。

🏠

数据私有

单文件 SQLite，无云端同步通道，无遥测。默认只绑 127.0.0.1；对外暴露由你的反代决定。

常见问题

技术问题快速答案

真的零第三方依赖吗？
免费版与商业版都是：只用 Python 标准库（sqlite3 / http.server / hashlib / json），Python 3.11+ 即可运行。CI 里有静态扫描守门：包内任何顶层 import pasm 都会让测试失败。
692 项守门测试是什么？
四套自动化测试：端到端 46 项（渠道/状态机/闸门/审计）、大脑层 34 项（含 PASM 真实集成）、功能补强 37 项（本轮全部 bug 修复与新功能）、HTTP 层 48 项（真实服务全链路）。全部退出码 0。
MCP 客户端怎么接？
在 MCP 客户端配置里启动 pasm-omni --db omni.db serve-mcp，initialize 后即可见 30 个工具。高危工具先用 CLI grant 授权。
数据库能迁到 PostgreSQL 吗？
当前存储层为 SQLite 单文件（FTS5 内置）。存储访问全部收敛在 store.py，换库只需替换该层；多租户 SaaS 化在路线图上，不在内核范围。
挂件会影响站点性能吗？
挂件为单文件原生 JS（无框架、无依赖），约 10KB；轮询仅在面板打开时进行，关闭即停。
